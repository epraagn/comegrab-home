# Stack Tower

A simple, addictive block-stacking game. Tap, click or press Space to drop the block and line it up with the tower below.

## Play locally
Open `index.html` in any browser.

## Host free on GitHub Pages
1. Upload these files to a GitHub repository.
2. Go to Settings > Pages.
3. Under Source, pick the `main` branch and the `/ (root)` folder, then Save.
4. Your game goes live at `https://<your-username>.github.io/<repo-name>/`.
